⚙️ Google Sheet Setup Guide

The website reads directly from your Google Sheet. Follow these steps to connect:

  1. Open your Google Sheet → File → Share → Publish to web
  2. Select "Entire Document" and "Web page", then click Publish
  3. Copy your Sheet ID from the URL bar (the long string between /d/ and /edit)
  4. Edit the SITE_CONFIG block at the top of this HTML file and paste your Sheet ID
  5. Make sure your sheet tabs are named exactly: Admin Updates, Timetable, Exams, Personnel
